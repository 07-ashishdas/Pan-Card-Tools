# Pan Card Tools

A free online tool to resize photos and signatures for UTI and NSDL PAN card applications. Everything runs in your browser — no uploads to any server.

## Features

- Resize photo to 213×213 px (UTI) or 3.5×2.5 cm (NSDL)
- Resize signature to 400×200 px (UTI) or 4.5×2.0 cm (NSDL)
- Drag & drop or click to upload
- Automatic B&W conversion for UTI signature
- 100% client-side processing

## Usage

```bash
npm install
npm run dev
```

Open the URL shown in the terminal, upload your images, select your portal (UTI/NSDL), and click resize.

## Build

```bash
npm run build
```

Output goes to `dist/`.
